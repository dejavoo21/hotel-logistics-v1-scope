# Manual Testing Documentation

This directory contains all the project prompts and documentation files for the Hotel Logistics & Maintenance App.

## Contents

- **CLAUDE.md** - Context file for Claude Code with project overview, key concepts, and development guidelines
- **project_spec.md** - Detailed project specification including features, data models, and technical requirements
- **project_status.md** - Project milestones, completed work, and current focus areas
- **environment_setup.md** - Environment setup instructions and tools used
- **Hotel Logistics v1 scope.txt** - Original scope document outlining the v1 features and future integration plans

## Purpose

These files serve as:
- Reference documentation for understanding the project requirements
- Prompts for AI assistants and development tools
- Historical record of project planning and specifications
- Testing guidelines and manual testing scenarios

## Usage

Use these files as reference when:
- Performing manual testing of features
- Understanding the project scope and requirements
- Creating test scenarios based on the specifications
- Validating implementations against the original requirements
